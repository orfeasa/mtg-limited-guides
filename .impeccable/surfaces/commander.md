## Scope and mode

Read: a phone reference for a first-time Magic player learning multiplayer Commander with friends.

## Audience, job, and task

Find the next turn step or a short rules reminder without leaving the game. Keep turn order visible first, followed by casting, combat, Commander-specific rules and expandable keywords.

## Chosen direction

Neutral Magic table reference: charcoal, white and orange, with condensed headings and highly legible body text. The user explicitly rejected Hobbit styling. This route has no set-specific material metaphor, parchment, forest palette or serif headings. Inherit accessibility and typography assets from the shared site without inheriting a set identity.

## Constraints

Preserve rules text, plain anchor navigation, native disclosures, 44px navigation targets, 48px disclosure targets, and the single-column phone layout. No new JavaScript or account requirement.
